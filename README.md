# Chính Thống Giáo — website tĩnh

## Cách public lên GitHub Pages

1. Tạo repository trên GitHub, ví dụ: `chinhthonggiao`.
2. Upload toàn bộ file trong thư mục này lên repository.
3. Vào `Settings` → `Pages`.
4. Ở phần `Build and deployment`, chọn:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Bấm `Save`.
6. Chờ GitHub tạo link website.

## Cách sửa nội dung

- Trang chủ: sửa `index.html`.
- Giao diện: sửa `style.css`.
- Tương tác đóng/mở box: sửa `script.js`.
- Nội dung Chương 0: sửa các file trong thư mục `chuong-0/`.

## Sau này mua tên miền

Khi mua tên miền, vào `Settings` → `Pages` → `Custom domain`, nhập domain và cấu hình DNS theo hướng dẫn của GitHub.
